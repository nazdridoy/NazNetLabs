# NazNetLabs

A collection of network labs, configurations, and experiments covering various platforms.

## Current Labs

### MikroTik
- **[Mikrotik-Labs](./Mikrotik-Labs)**: RouterOS configurations including PCQ bandwidth management, Queue Tree, time-based web filtering, and DNS-based layer 7 blocking.

### Windows
- **[Windows](./Windows)**: Labs for Windows 11 client customization (taskbar, start menu, multitasking) and future Windows Server administration.

### Linux
- **[Linux](./Linux)**: RHEL labs covering user/group administration, KVM guest image builds, DNS with BIND and Unbound, and a full Postfix/Dovecot mail server stack.

## Roadmap

Planned additions for future labs:

- **[Cisco](./Cisco)**: IOS/IOS-XE switching and routing.
- **[Juniper](./Juniper)**: Junos OS routing and switching.
- **[FortiGate](./FortiGate)**: Firewall policies and VPN configurations.
