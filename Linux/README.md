# Linux Networking Labs

A collection of hands-on labs for Linux administration and networking.

## RHEL Labs

Practical labs for Red Hat Enterprise Linux system and network administration.

- **[RHEL 8 User, Group & Network Administration](./RHEL-Labs/RHEL8-User-Group-Network-Admin.md)**: Basic server setup on RHEL 8 including static IP, department groups, and directory permissions.
- **[RHEL 7 KVM Guest Image Build](./RHEL-Labs/RHEL7-KVM-Guest-Image-Build.md)**: Build a RHEL 7.9 KVM image identical to Red Hat's official KVM Guest Image, with cloud-init, serial console, and qemu-guest-agent, then import it into GNS3. Covers both the manual install method and the automated Red Hat Image Builder (`osbuild`) approach.
- **[RHEL 7 DNS: BIND (Authoritative) and Unbound (Caching)](./RHEL-Labs/RHEL7-DNS-BIND-and-Unbound.md)**: Full DNS infrastructure setup covering BIND as an authoritative name server with DNSSEC, zone transfers, DDNS integration, and Unbound as a caching recursive resolver with DNSSEC validation.
- **[RHEL 7 Mail Server: Postfix and Dovecot](./RHEL-Labs/RHEL7-Mail-Server-Postfix-Dovecot.md)**: Complete internal mail server stack with Postfix (MTA), Dovecot (IMAP/POP3), TLS encryption, SpamAssassin filtering, and Thunderbird client setup.
